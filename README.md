# 0xterricola — Project Policies

This repository contains the default security and disclosure policies for open-source projects maintained by **0xterricola**.

These projects may include cryptography, cryptocurrency wallets, blockchain infrastructure, node tooling, developer tooling, experimental protocols, and other security-sensitive software.

## Policies

- [Security Policy](SECURITY.md)
- [Security Principles](SECURITY-PRINCIPLES.md)
- [Privacy Principles](PRIVACY-PRINCIPLES.md)
- [AI-Assisted Development](AI-ASSISTED-DEVELOPMENT.md)

GitHub uses `SECURITY.md` and `.github/VULNERABILITY_REPORT.yml` from this repository as defaults for repositories that do not provide their own versions.

Individual repositories may contain additional threat models, security reviews, limitations, privacy disclosures, or project-specific security policies. Project-specific documentation takes precedence when it is more specific.

## Development status

Projects maintained by 0xterricola may be experimental or under active development.

Unless a repository explicitly states otherwise:

- the software has not undergone a formal independent security audit;
- no claim is made that the software is free from vulnerabilities;
- cryptographic, wallet, networking, and protocol functionality should be independently reviewed before use in high-value or security-critical environments.

Security reports are welcome. See [SECURITY.md](SECURITY.md).
